# 援建項目（Installations）與項目類型

援建項目記錄機構建造或捐贈的基礎設施與設備，例如學校、橋樑、道路、水塔等。項目類型則用來在援建項目頁面分組顯示。

## 援建項目欄位

- **標題（title）**：項目名稱，例如「貴州希望小學」。
- **地點（location）**：項目所在地，例如「貴州省畢節市」。
- **描述（description）**：項目的詳細介紹，使用所見即所得編輯器。
- **URL 別名（slug）**：網址識別碼，例如 `hope-primary-school-guizhou`。
- **類型（type）**：關聯到「項目類型」集合，決定項目在網站上的分組。
- **竣工日期（completionDate）**：可選，顯示項目完成時間。
- **照片（photos）**：可上傳多張照片，展示項目成果。
- **已發布（published）**：控制項目是否公開。
- **SEO 設定**：可設定搜尋標題、描述與分享圖片。

## 項目類型欄位

- **識別碼（key）**：程式碼使用的穩定識別碼，例如 `school`。
- **標籤（label）**：顯示名稱。
- **排序（sortOrder）**：控制援建項目頁面上的分組順序，數字越小越靠前。

## 操作提示

- 建議先建立「項目類型」，再建立援建項目。
- 援建項目可與活動、捐款、網誌文章互相關聯，讓網站內容更有脈絡。
- 發布或更新後，前端快取會自動重新整理。
