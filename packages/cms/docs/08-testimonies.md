# 見證（Testimonies）

「見證」集合用來發布受益者、義工、捐贈者與支持者的故事。

## 欄位說明

- **姓名（name）**：人物名稱。
- **角色（role）**：例如「演員」、「歌手」、「受益者」、「義工」。
- **重點推薦（highlighted）**：勾選後會作為重點人物推薦（例如名人或貴賓）。
- **照片（photos）**：可上傳多張照片。
- **簡介（synopsis）**：列表中顯示的短句或摘要。
- **內容（content）**：完整的見證或故事，使用所見即所得編輯器。
- **已發布（published）**：控制見證是否公開。

## 操作提示

- 建議為每位人物準備一張清晰的大頭照或代表性照片。
- 重點推薦可用於首頁或特別區塊展示。
- 發布或更新後，前端快取會自動重新整理。
