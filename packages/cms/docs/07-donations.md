# 捐款記錄（Donations）

「捐款記錄」集合記錄機構收到的每一筆捐款，包含捐贈者資料、金額、轉賬日期以及支持的項目或活動。

## 欄位說明

- **姓名（name）**：捐贈者名稱。
- **電子郵件（email）**：用於寄送捐款收據與後續聯絡。
- **電話（phone）**：可選。
- **金額（amount）**：所選幣別的捐款金額。
- **幣別（currency）**：例如 HKD、USD、CNY、TWD、EUR、GBP。
- **轉賬日期（transferDate）**：捐款實際發生的日期。
- **付款方式（paymentMethod）**：例如銀行轉賬、FPS、PayMe、支票、現金、其他。
- **留言（message）**：捐贈者的可選留言或寄語。
- **援建項目（installations）**：此捐款支持的援建項目。
- **活動（events）**：此捐款分配到的活動。
- **收據圖片（receipts）**：捐贈者上傳的轉賬證明或收據照片。
- **狀態（status）**：
  - **待確認（pending）**：尚未確認款項。
  - **已確認（confirmed）**：款項已收到並確認。
  - **已退款（refunded）**：已退款給捐贈者。
  - **已取消（cancelled）**：作廢或無效的捐款記錄。
- **已寄收據（receiptSent）**：是否已向捐贈者發送捐款收據。
- **備註（notes）**：僅限工作人員查看，不顯示給捐贈者。

## 操作提示

- 大部分捐款記錄會由「捐款表單」自動建立（詳見「表單與提交」說明）。
- 手動新增時請確認幣別、金額與狀態，避免後續對帳錯誤。
- 可透過活動與援建項目的關聯，讓公開頁面展示捐款的實際用途。
