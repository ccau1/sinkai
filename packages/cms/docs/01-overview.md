# 管理後台概覽

歡迎使用善啓慈善基金會內容管理系統（CMS）管理後台。本說明文件會逐步帶你了解後台各區塊的用途與日常操作方式。

## 適用對象

- 網站管理員（admin）：可管理所有內容、使用者與系統設定。
- 網誌編輯（blog_editor）：主要負責網誌文章與媒體。
- 援建編輯（installation_editor）：主要負責援建項目、見證與相關活動。
- 唯讀使用者（read_only）：可檢視內容但無法編輯。

## 使用本說明文件

左側選單會列出所有說明主題。點選任一主題即可在右側閱讀詳細內容。本文件會隨著網站功能更新而持續擴充。

## 核心操作原則

- **編輯後記得發布**：大部分內容都有「已發布」核取方塊，未發布的內容不會顯示在公開網站上。
- **善用多語系**：需要時可為內容提供不同語系版本。
- **保持圖片輕量**：建議上傳圖片大小控制在 500KB 以下，最大不超過 12MB。
- **遇到問題先看權限**：如果你找不到某個編輯按鈕，通常代表帳號角色沒有對應權限。

## 常用區塊

- **網站**：網誌、援建項目、見證、活動、捐款記錄、表單、表單提交。
- **媒體**：圖片與檔案，以及分類管理。
- **設定**：導覽選單、聯絡設定。
- **系統**：使用者管理。

如果你對某個區塊不熟悉，請直接點選左側對應的說明頁面。
