# 使用者（Users）與權限

「使用者」集合管理可以登入後台的使用者帳號。每個使用者會被指派一或多個角色，並可額外設定特殊權限。

## 角色說明

- **admin（管理員）**：擁有完整後台權限，包括管理其他使用者、刪除資料等。
- **blog_editor（網誌編輯）**：可編輯網誌、媒體與相關內容。
- **installation_editor（援建編輯）**：可編輯援建項目、活動、捐款、見證等。
- **read_only（唯讀）**：只能檢視內容，無法新增、編輯或刪除。

## 額外權限

除了角色之外，也可針對個別使用者開啟以下權限：

- **管理使用者（manageUsers）**：可管理其他使用者。
- **編輯網誌（editBlogs）**：可編輯網誌內容。
- **編輯援建項目（editInstallations）**：可編輯援建項目與相關內容。
- **上傳媒體（uploadMedia）**：可上傳媒體檔案。
- **刪除媒體（deleteMedia）**：可刪除媒體檔案。
- **檢視未發布內容（viewUnpublished）**：可查看尚未發布的內容。

## 操作提示

- 建議依照工作職責給予最小必要權限，避免誤操作。
- Admin 角色與「管理使用者」權限都擁有使用者管理功能，請謹慎授予。
- 若某位使用者應該能編輯某類內容但找不到選單，通常是角色或權限未開啟。
- 密碼重設與帳號鎖定等安全機制由 Payload 自動管理。
