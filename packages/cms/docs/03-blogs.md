# 網誌（Blogs）

「網誌」集合用來發布新聞、故事、活動報告與機構文章。

## 欄位說明

- **別名（slugName）**：URL 安全的識別碼，例如 `mountain-area-reality`。同一別名在所有語系中必須唯一。
- **標題（title）**：文章標題，可設定多語系。
- **摘要（excerpt）**：搜尋結果與文章清單顯示的簡介，可設定多語系。
- **內容（content）**：文章主文，使用所見即所得編輯器。
- **封面圖片（coverImage）**：必填，會顯示在文章列表與詳細頁頂部。
- **日期（date）**：網站上顯示的發布日期。首次發布時會自動帶入發布時間，也可手動調整作為回溯日期。
- **援建項目（installations）**：可關聸此篇文章提到的援建項目，讓讀者直接跳轉了解詳情。
- **已發布（published）**：控制文章是否公開顯示。
- **SEO 設定**：在 SEO 分頁中可設定搜尋標題、描述與分享圖片。

## 操作提示

- 文章發布後，系統會自動產生短網址識別碼（shortId），請勿手動修改。
- 與援建項目關聸可強化內容脈絡，也能讓項目頁面反向展示相關文章。
- 編輯或發布後，前端快取會自動重新整理。
