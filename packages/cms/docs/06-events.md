# 活動（Events）

「活動」集合用來管理慈善行程、籌款活動、建校行程等。

## 欄位說明

- **標題（title）**：活動名稱。
- **開始日期（startDate）**：活動首日。
- **結束日期（endDate）**：單日活動可留空。
- **描述（description）**：活動詳情，使用所見即所得編輯器。
- **封面圖片（coverImage）**：活動頁頂部圖片。
- **地址（addresses）**：可新增多個地址，例如集合點或服務地點。
- **目標金額（targetAmount）**：資助該活動所需的捐款金額，可留空。
- **目標幣別（targetCurrency）**：與目標金額搭配使用。
- **援建項目（installations）**：該活動資助或建成的援建項目。
- **捐款（donations）**：分配到該活動的捐款記錄。
- **已發布（published）**：控制活動是否公開。

## 操作提示

- 活動與捐款、援建項目互相關聯，可讓訪客清楚看到一筆捐款如何轉化為實際成果。
- 目標金額僅供顯示，不會自動鎖住捐款功能。
- 發布或更新後，前端快取會自動重新整理。
