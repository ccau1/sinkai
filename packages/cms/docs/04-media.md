# 媒體（Media）與媒體分類

媒體是網站所有圖片與檔案的集中管理區。媒體分類則用來整理圖片，並控制哪些分類會顯示在公開圖庫頁面。

## 媒體欄位

- **替代文字（alt）**：圖片的無障礙描述，有助於 SEO 與視障使用者。
- **分類（category）**：可將圖片歸入某個媒體分類。
- **標籤（tags）**：用於後台篩選與分組，不會直接顯示在公開網站。
- **排序（sortOrder）**：在該分類內的位置，數字越小越靠前。
- **隱藏（hidden）**：在公開圖庫中隱藏此媒體，但不會刪除檔案。
- **可見性（visibility）**：
  - **公開（public）**：所有人皆可透過網址存取。
  - **私密（private）**：僅已登入使用者可存取，適合內部文件或尚未公開的素材。

## 媒體分類欄位

- **識別碼（slug）**：程式碼使用的穩定識別碼，例如 `snow-disaster`。
- **標籤（label）**：區塊標題上方的小號大寫眉題文字。
- **標題（title）**：分類名稱。
- **描述（description）**：分類標題下方的可選說明。
- **排序（sortOrder）**：在公開圖庫頁面上的順序。
- **顯示於圖庫（showInGallery）**：取消勾選即可在公開圖庫中隱藏此分類。

## 操作提示

- 上傳前請先壓縮圖片，建議不超過 500KB，最大 12MB。
- 私密媒體只會提供給已登入使用者，公開網站上的圖片請保持「公開」。
- 分類的 `showInGallery` 與個別媒體的 `hidden` 會共同決定圖庫頁面顯示內容。
